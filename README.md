# Discord Event Bot

방학 기간 동안 정해진 요일에 로컬 PC에서 켜서 운영하는 Discord 이벤트 봇입니다.

## 기능

- 이벤트 타임마다 `/오픈`으로 새 참가 명단 모집
- 메인게임: `신뢰 거래`, `모래성 게임` 중 하나를 매 회차 먼저 진행
- 미니게임: 일반 밸런스(A/B 비공개 투표 + 1인 1발언 토론), 4선 폭탄 해체, 관리자 시점 타일, 돌 세공 예측, 상위 3명 견제 중 하나를 메인 콘텐츠 뒤에 진행
- 라운드 마감 시 자동 정산
- 유저별 누적 점수와 랭킹 저장
- SQLite 파일 기반 저장이라 별도 DB 서버 불필요
- 로컬 PC에서 필요한 시간에만 실행 가능

## 설치

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

`.env` 파일을 열어서 `DISCORD_TOKEN` 값을 넣으세요.

빠른 슬래시 명령어 등록을 원하면 `GUILD_ID`도 넣으세요.

운영자 명령어를 특정 역할도 사용할 수 있게 하려면 `OPERATOR_ROLE_IDS`에 역할 ID를 넣으세요.
여러 역할은 쉼표로 구분합니다.

```env
OPERATOR_ROLE_IDS=123456789012345678,987654321098765432
```

## Discord 개발자 포털 설정

봇은 기본 인텐트로 실행됩니다. Developer Portal에서 Message Content Intent나 Server Members Intent를 따로 켤 필요는 없습니다.

초대 권한 예시:

- Send Messages
- Use Slash Commands
- Create Public Threads
- Create Private Threads
- Send Messages in Threads
- Manage Threads
- Manage Messages
- Read Message History

`Create Private Threads`는 신뢰 거래에서 매칭된 2명만 참여하는 세트별 협상방을 만드는 데 필요합니다. `Manage Threads`는 신뢰 거래 결과 공개 후 비공개방을 잠그고, 익명 미니게임 토론방의 일반 채팅도 차단하는 데 필요합니다. `Manage Messages`는 권한 설정이 실패했을 때 일반 메시지를 삭제하는 보호 장치로도 사용됩니다.

## 명령어

### 운영자용

- `/오픈`
- `/start 메인게임 미니게임`
- `/미니게임 게임`
- `/라운드마감`
- `/이벤트종료`
- `/세공진행`
- `/데이터백업`

운영자 명령어는 기본적으로 서버 관리자 외에는 표시·사용할 수 없습니다. Discord의 명령어 권한 화면에서 `OPERATOR_ROLE_IDS`에 등록한 운영자 역할을 허용(✓)하면, 해당 역할도 명령어를 볼 수 있고 사용할 수 있습니다.

이벤트를 시작할 때 운영자가 먼저 `/오픈`을 실행합니다. 봇은 전체 게임 진행 흐름과 `참여하기` 버튼을 게시합니다. 버튼을 누른 유저만 이번 이벤트의 메인게임·미니게임·익명 토론에 참여할 수 있으며, 첫 게임이 시작되면 참가 명단이 자동으로 마감됩니다. 다음 이벤트 타임에는 `/오픈`을 다시 실행해야 하며 이전 참가 명단은 이어지지 않습니다.

개발 중 전체 게임을 끝까지 진행하지 않고 현재 이벤트를 정리하려면 `/이벤트종료`를 사용합니다. 진행 중인 라운드는 점수 정산 없이 취소되고, 자동 마감 예약과 남아 있는 버튼·토론방도 비활성화됩니다.

`/start`에서 메인게임 1개와 미니게임 1개를 함께 선택합니다. 먼저 메인게임 설정 창이 열리고, 메인게임 정산이 끝나면 결과 메시지에 처음 선택한 미니게임의 `설정 후 시작` 버튼이 표시됩니다. 버튼을 누른 뒤 제목, 진행 시간, 선택지, 정답 칸 같은 세부 내용을 입력하면 미니게임이 시작됩니다.

메인게임 없이 미니게임만 진행할 때는 `/오픈`으로 참가자를 모집한 뒤 `/미니게임`에서 게임을 선택합니다. 설정 창을 제출하면 선택한 미니게임이 바로 시작됩니다.

미니게임: 일반 밸런스 예시:

```text
/start 메인게임:신뢰 거래 미니게임:일반 밸런스
```

처음 `/start`에서 미리 선택합니다. 메인게임이 끝난 뒤 표시되는 버튼을 누르고 제목, 진행 시간, A 선택지, B 선택지를 입력합니다.

4선 폭탄 해체 게임 예시:

```text
/start 메인게임:신뢰 거래 미니게임:4선 폭탄 해체
```

4선 폭탄 해체 게임은 빨강, 파랑, 검정, 흰색 버튼 중 하나를 고르는 게임입니다. 설정 창에서 제목, 진행 시간, 안전 색, 관리자의 힌트를 입력합니다. 안전 색은 관리자가 직접 정하며 마감 전까지 공개되지 않고, 힌트만 공개됩니다. 유저들은 해체 토론방에서 한 번씩 심리전과 블러핑을 한 뒤 색 아이콘 버튼 하나를 선택합니다. 마감 후 안전 색을 고른 유저만 +1점을 받습니다.

관리자 시점 타일 게임 예시:

```text
/start 메인게임:신뢰 거래 미니게임:관리자 시점 타일
```

관리자 시점 타일 게임은 3X3 칸 중 관리자가 고른 칸을 유저들이 맞히는 고득점 게임입니다. 설정 창에서 제목, 진행 시간, 정답 칸, 관리자의 선택 이유를 입력합니다. 선택 이유는 모두에게 공개되는 단서이고, 정답 칸은 마감 전까지 공개되지 않습니다. 유저들은 생성된 추리방에서 한 번씩 의견을 남기며 분탕, 블러핑, 역추리로 다른 유저를 흔든 뒤 버튼으로 최종 칸을 선택합니다. 정답자는 다른 게임보다 큰 보상인 +3점을 받습니다.

돌 세공 예측 게임 예시:

```text
/start 메인게임:신뢰 거래 미니게임:돌 세공 예측
```

설정 창에서 제목과 진행 시간을 입력합니다. 돌 세공 예측 게임은 유저들이 0강화부터 6강화 중 최종 단계를 예측하는 게임입니다. 집계가 끝난 뒤 운영자가 `/세공진행`을 실행하면 관리자 전용 세공 임배드와 `세공 시도` 버튼이 나옵니다. 강화 성공 확률은 0→1·1→2는 80%, 2→3·3→4는 60%, 4→5는 50%, 5→6은 30%입니다. 실패하거나 6강화까지 성공하면 자동으로 결과와 정산이 공개됩니다. 처음 실패하기 직전의 강화 단계를 맞힌 유저에게 0~2강화는 +1점, 3~4강화는 +2점, 5강화는 +3점, 6강화는 +4점을 지급합니다.

상위 3명 견제 게임 예시:

```text
/start 메인게임:신뢰 거래 미니게임:상위 3명 견제
```

설정 창에서 제목과 진행 시간을 입력합니다. 이번 이벤트 참가자 중 게임 시작 시점의 점수 상위 3명이 후보가 되고, 참가자들은 세 후보 또는 `선택하지 않는다` 중 하나를 고릅니다. `선택하지 않는다` 득표수가 세 후보 득표수 합보다 많으면 세 후보를 제외한 이번 이벤트 참가자 전원 +1점입니다. 그렇지 않으면 세 후보 중 가장 많이 선택된 한 명이 -1점입니다.

신뢰 거래(메인) 예시:

```text
/start 메인게임:신뢰 거래 미니게임:일반 밸런스
```

설정 창에서 제목과 매칭 준비 시간을 입력합니다. `/오픈`에서 `참여하기`를 누른 유저가 자동으로 게임에 참여합니다. 시간이 끝나면 봇이 참여자를 무작위로 2명씩 한 세트로 매칭하고, 세트마다 두 사람만 볼 수 있는 비공개 협상방을 만듭니다. 각자 신뢰 또는 배신을 비공개로 확정하며, 서로의 선택은 마감 후 해당 협상방에서만 공개됩니다. 전체 채널에는 `신뢰 : n · 단독 배신 : n · 동시 배신 : n` 형식으로 결과 수만 공개되며, 미선택이 있으면 `미선택 : n`이 추가됩니다. 상호 신뢰는 각 `+1점`, 한 명만 배신하면 배신자 `+2점`·상대 `0점`, 둘 다 배신하면 각 `-1점`으로 정산됩니다. 참여자가 홀수면 한 명은 무작위로 매칭 대기 처리됩니다.

모래성 게임(메인) 예시:

```text
/start 메인게임:모래성 게임 미니게임:일반 밸런스
```

설정 창에서 제목과 매칭 준비 시간을 입력합니다. 규칙 안내는 채널의 모든 참가자에게 공개되며, 준비시간이 끝나면 `/오픈`에서 참가 등록한 유저를 무작위로 1:1 매칭해 실제 게임을 시작합니다.

1. 각 참여자가 1~10 중 모래성이 무너질 횟수를 정합니다.
2. 실제 무너질 횟수는 정한 횟수끼리 뺀 값(두 수의 차이)으로 결정됩니다.
3. 참여자는 번갈아가며 `포기하기` 또는 `모래 덜기`를 결정합니다.

- 둘 다 포기 선택 시: 서로 -1점
- 한 명이 포기(A), 다른 한 명이 모래 덜기(B) 선택 시:
  - 덜기 성공: A는 -1점, B는 +2점
  - 무너짐: B는 -1점, A는 +1점
- 서로 덜기를 하다 무너진 경우: 그 턴의 사람이 -1점

전체 이벤트는 `/start`에서 `메인게임 2개 중 1개 + 미니게임 5개 중 1개`를 한 번에 고르고 `선택한 메인게임 → 선택한 미니게임` 순서로 진행합니다. 메인게임 없이 진행하려면 `/미니게임`으로 미니게임 하나를 바로 시작할 수 있습니다.

## 운영 예시

모든 이벤트는 다음 순서로 시작합니다.

1. 운영자가 이벤트 타임마다 `/오픈` 실행
2. 유저들이 안내문의 `참여하기` 버튼으로 참가 등록
3. 운영자가 `/start`에서 메인게임과 미니게임을 함께 선택하고 메인게임 시작 — 이 시점부터 참가 명단 마감
4. 메인게임 정산 뒤 결과 메시지의 버튼으로 처음 선택한 미니게임 설정 및 시작
5. 해당 명단의 유저만 그날의 메인게임과 미니게임 진행

아래 미니게임은 처음 `/start`에서 미리 선택하고, `신뢰 거래` 또는 `모래성 게임`이 끝난 뒤 결과 메시지의 버튼으로 시작합니다.

미니게임: 일반 밸런스:

1. 운영자가 처음 `/start`에서 `일반 밸런스`를 미니게임으로 선택하고, 메인게임 종료 뒤 설정 버튼을 누름
2. 유저들이 버튼으로 A/B 비공개 투표
3. 생성된 토론 스레드의 `익명 발언하기` 버튼을 눌러 1인 1회 발언
4. 시간이 끝나면 자동 마감, 필요하면 `/라운드마감`으로 수동 마감
5. 봇이 다수파와 선택자 명단 공개 후 다수파에게 +1점

미니게임: 4선 폭탄 해체:

1. 운영자가 처음 `/start`에서 `4선 폭탄 해체`를 미니게임으로 선택하고, 메인게임 종료 뒤 설정 버튼을 누름
2. 설정 창에서 빨강, 파랑, 검정, 흰색 중 안전 색과 공개 힌트를 입력
3. 유저들이 해체 토론방의 `익명 발언하기` 버튼으로 한 번씩 심리전과 블러핑
4. 유저들이 색 아이콘 버튼 하나를 선택
5. 시간이 끝나면 봇이 힌트, 해체 성공 색, 선택 분포를 공개하고 성공자에게 +1점

신뢰 거래 라운드:

1. 운영자가 `/start`의 메인게임으로 `신뢰 거래`를 선택
2. 매칭 준비 시간이 끝나면 봇이 `/오픈` 참가자만 무작위로 2명씩 매칭
3. 참여자가 홀수라면 한 명은 이번 회차 매칭 대기
4. 세트별 비공개 협상방에서 각 유저가 신뢰 또는 배신을 비공개로 확정
5. 마감 후 각 협상방에는 두 사람의 선택과 점수 정산을 공개하고 방을 잠금
6. 전체 채널에는 결과 유형별 세트 수만 공개

모래성 게임 라운드:

1. 운영자가 `/start`의 메인게임으로 `모래성 게임`을 선택
2. 매칭 준비가 끝나면 봇이 `/오픈` 참가자를 무작위로 1:1 매칭
3. 각 참가자가 1~10 중 자신의 숫자를 비공개로 확정
4. 봇이 정한 선공부터 번갈아 포기하거나 모래를 덜기
5. 모든 짝이 끝나거나 10분 제한 시간이 지나면 짝별 숫자 차이, 결과, 점수 정산을 공개

미니게임: 관리자 시점 타일:

1. 운영자가 처음 `/start`에서 `관리자 시점 타일`을 미니게임으로 선택하고, 메인게임 종료 뒤 설정 버튼에서 정답 칸과 설명을 입력
2. 유저들이 추리방에서 한 번씩 추리, 분탕, 블러핑 의견 공유
3. 유저들이 3X3 버튼 중 정답이라고 생각하는 칸 선택
4. 시간이 끝나면 봇이 정답 칸, 선택 분포, 정답자 명단을 공개하고 정답자에게 +3점

미니게임: 돌 세공 예측:

1. 운영자가 처음 `/start`에서 `돌 세공 예측`을 미니게임으로 선택하고, 메인게임 종료 뒤 설정 버튼을 누름
2. 유저들이 0강화부터 6강화 중 최종 단계를 예측
3. 시간이 끝나면 봇이 예측 분포를 집계
4. 운영자가 `/세공진행` 실행
5. 관리자 전용 `세공 시도` 버튼을 실패할 때까지 누름
6. 봇이 세공 기록, 최종 강화 단계, 정답자 명단을 공개하고 결과 단계에 따라 0~2강화 +1점, 3~4강화 +2점, 5강화 +3점, 6강화 +4점 지급

미니게임: 상위 3명 견제:

1. 운영자가 처음 `/start`에서 `상위 3명 견제`를 미니게임으로 선택하고, 메인게임 종료 뒤 설정 버튼을 누름
2. 봇이 이번 이벤트 참가자 중 현재 점수 상위 3명을 후보로 공개
3. 유저들이 후보 3명 또는 `선택하지 않는다` 중 하나에 투표
4. 시간이 끝나면 봇이 조건에 따라 상위 3명 제외 전원 +1점 또는 최다 득표 후보 -1점 정산
