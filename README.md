# Discord Event Bot

방학 기간 동안 정해진 요일에 로컬 PC에서 켜서 운영하는 Discord 이벤트 봇입니다.

## 기능

- 일반 라운드: A/B 비공개 투표 + 1인 1발언 토론
- 라운드 마감 시 자동 정산
- 유저별 누적 점수와 랭킹 저장
- SQLite 파일 기반 저장이라 별도 DB 서버 불필요
- 로컬 PC에서 필요한 시간에만 실행 가능

## 설치

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

`.env` 파일을 열어서 `DISCORD_TOKEN` 값을 넣으세요.

빠른 슬래시 명령어 등록을 원하면 `GUILD_ID`도 넣으세요.

운영자 명령어를 특정 역할도 사용할 수 있게 하려면 `OPERATOR_ROLE_IDS`에 역할 ID를 넣으세요.
여러 역할은 쉼표로 구분합니다.

```env
OPERATOR_ROLE_IDS=123456789012345678,987654321098765432
```

## Discord 개발자 포털 설정

봇은 기본 인텐트로 실행됩니다. Developer Portal에서 Message Content Intent나 Server Members Intent를 따로 켤 필요는 없습니다.

초대 권한 예시:

- Send Messages
- Use Slash Commands
- Create Public Threads
- Send Messages in Threads
- Manage Messages
- Read Message History

`Manage Messages`는 1인 1발언 제한에서 두 번째 발언을 삭제하기 위해 필요합니다.

```powershell
.\run.ps1
```

봇을 끄더라도 `data/event_game.sqlite3`에 점수와 기록이 남습니다.

## 명령어

### 운영자용

- `/start 게임`
- `/라운드마감`
- `/세공진행`
- `/점수수정 사용자 점수 사유`
- `/데이터백업`

운영자 명령어는 관리자/서버 관리 권한이 있거나 `OPERATOR_ROLE_IDS`에 등록된 역할이 있는 사람만 사용할 수 있습니다.

`/start`는 게임 종류만 선택합니다. 선택 후 뜨는 설정 창에 제목, 진행 시간, 선택지, 정답 칸 같은 세부 내용을 입력하면 게임이 시작됩니다. 시간이 끝나면 자동으로 마감하고 결과/통계를 채널에 올립니다.

일반 밸런스 게임 예시:

```text
/start 게임:일반 밸런스
```

설정 창에서 제목, 진행 시간, A 선택지, B 선택지를 입력합니다.

4선 폭탄 해체 게임 예시:

```text
/start 게임:4선 폭탄 해체
```

4선 폭탄 해체 게임은 빨강, 파랑, 검정, 흰색 버튼 중 하나를 고르는 게임입니다. 설정 창에서 제목, 진행 시간, 안전 색, 관리자의 힌트를 입력합니다. 안전 색은 관리자가 직접 정하며 마감 전까지 공개되지 않고, 힌트만 공개됩니다. 유저들은 해체 토론방에서 한 번씩 심리전과 블러핑을 한 뒤 색 아이콘 버튼 하나를 선택합니다. 마감 후 안전 색을 고른 유저만 +1점을 받습니다.

관리자 시점 타일 게임 예시:

```text
/start 게임:관리자 시점 타일
```

관리자 시점 타일 게임은 3X3 칸 중 관리자가 고른 칸을 유저들이 맞히는 고득점 게임입니다. 설정 창에서 제목, 진행 시간, 정답 칸, 관리자의 선택 이유를 입력합니다. 선택 이유는 모두에게 공개되는 단서이고, 정답 칸은 마감 전까지 공개되지 않습니다. 유저들은 생성된 추리방에서 한 번씩 의견을 남기며 분탕, 블러핑, 역추리로 다른 유저를 흔든 뒤 버튼으로 최종 칸을 선택합니다. 정답자는 다른 게임보다 큰 보상인 +3점을 받습니다.

돌 세공 예측 게임 예시:

```text
/start 게임:돌 세공 예측
```

설정 창에서 제목과 진행 시간을 입력합니다. 돌 세공 예측 게임은 유저들이 0강화부터 6강화 중 최종 단계를 예측하는 게임입니다. 집계가 끝난 뒤 운영자가 `/세공진행`을 실행하면 관리자 전용 세공 임배드와 `세공 시도` 버튼이 나옵니다. 운영자가 버튼을 누를 때마다 다음 강화가 50% 확률로 성공하거나 실패하며, 실패하거나 6강화까지 성공하면 자동으로 결과와 정산이 공개됩니다. 처음 실패하기 직전의 강화 단계를 맞힌 유저에게 +1점을 지급합니다.

상위 3명 견제 게임 예시:

```text
/start 게임:상위 3명 견제
```

설정 창에서 제목과 진행 시간을 입력합니다. 게임 시작 시점의 점수 상위 3명이 후보가 되고, 유저들은 세 후보 또는 `선택하지 않는다` 중 하나를 고릅니다. `선택하지 않는다` 득표수가 세 후보 득표수 합보다 많으면 상위 3명을 제외한 점수 기록 유저 전원 +1점입니다. 그렇지 않으면 세 후보 중 가장 많이 선택된 한 명이 -1점입니다.

## 운영 예시

일반 라운드:

1. 운영자가 `/start`에서 `일반 밸런스`를 선택
2. 유저들이 버튼으로 A/B 비공개 투표
3. 생성된 토론 스레드에서 1인 1회만 발언
4. `/start`로 시작했다면 시간이 끝날 때 자동 마감, 필요하면 `/라운드마감`으로 수동 마감
5. 봇이 다수파와 선택자 명단 공개 후 다수파에게 +1점

4선 폭탄 해체 라운드:

1. 운영자가 `/start`에서 `4선 폭탄 해체`를 선택
2. 설정 창에서 빨강, 파랑, 검정, 흰색 중 안전 색과 공개 힌트를 입력
3. 유저들이 해체 토론방에서 한 번씩 심리전과 블러핑
4. 유저들이 색 아이콘 버튼 하나를 선택
5. 시간이 끝나면 봇이 힌트, 해체 성공 색, 선택 분포를 공개하고 성공자에게 +1점

관리자 시점 타일 라운드:

1. 운영자가 `/start`에서 `관리자 시점 타일`을 선택하고 정답 칸과 설명을 입력
2. 유저들이 추리방에서 한 번씩 추리, 분탕, 블러핑 의견 공유
3. 유저들이 3X3 버튼 중 정답이라고 생각하는 칸 선택
4. 시간이 끝나면 봇이 정답 칸, 선택 분포, 정답자 명단을 공개하고 정답자에게 +3점

돌 세공 예측 라운드:

1. 운영자가 `/start`에서 `돌 세공 예측`을 선택
2. 유저들이 0강화부터 6강화 중 최종 단계를 예측
3. 시간이 끝나면 봇이 예측 분포를 집계
4. 운영자가 `/세공진행` 실행
5. 관리자 전용 `세공 시도` 버튼을 실패할 때까지 누름
6. 봇이 세공 기록, 최종 강화 단계, 정답자 명단을 공개하고 정답자에게 +1점

상위 3명 견제 라운드:

1. 운영자가 `/start`에서 `상위 3명 견제`를 선택
2. 봇이 현재 점수 상위 3명을 후보로 공개
3. 유저들이 후보 3명 또는 `선택하지 않는다` 중 하나에 투표
4. 시간이 끝나면 봇이 조건에 따라 상위 3명 제외 전원 +1점 또는 최다 득표 후보 -1점 정산
